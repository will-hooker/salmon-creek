# salmon-creek
Repo for "The Geology and Paleontology of Salmon Creek and Ludlowville Falls: Lansing, New York, U.S.A." Includes an R script that codes a phylogeny for all fossil taxa sampled from Salmon Creek. Preliminary cladograms are saved within the figures folder. A first draft of the manuscript detailing the stratigraphy and paleontology of this site can be found in this repo.
