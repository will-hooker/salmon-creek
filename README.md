# salmon-creek
Repo for Hooker et al. 2026, in review: "The Geology and Paleontology of Salmon Creek and Ludlowville Falls: Lansing, New York, U.S.A." (Bulletins of American Paleontology). 
Includes:
  (1) a link to the freely available online version of the text 
  (2) an R script that produces the phylogeny for all sampled fossil taxa (Appendix I Text-fig. 1)
  (3) a regularly updated table of all sampled fossil taxa (Appendix III Table 1)
